# 🚲 Bike Sharing Data Analysis Dashboard

## 📌 Deskripsi Proyek
Proyek ini menganalisis pola penyewaan sepeda menggunakan Bike Sharing Dataset periode 2011–2012.  
Analisis dilakukan untuk memahami tren waktu dan pengaruh faktor lingkungan terhadap jumlah penyewaan.

Hasil analisis ditampilkan dalam dashboard interaktif menggunakan Streamlit.

---

## 📊 Fitur Dashboard
- Total rentals
- Rata-rata penyewaan harian
- Tren penyewaan dari waktu ke waktu
- Penyewaan berdasarkan musim
- Perbandingan hari kerja vs akhir pekan
- Filter interaktif
